# 👁️ ARGUS Command Center (Frontend Application)

This directory contains the **Next.js 14 Tactical Command Center** for the **ARGUS** platform.

For full system architecture, multi-agent swarm documentation, mathematical formulations (LaMa-FFC), and demo walkthroughs, please see the [Root System README](../README.md).

---

## ⚡ Quick Start

```bash
# 1. Install dependencies
npm install --legacy-peer-deps

# 2. Run local development server
npm run dev

# 3. Open browser
# Navigate to http://localhost:3000
```

## 🛠️ Key Components in this Directory

* **`src/app/page.tsx`**: Unified operations dashboard (Google Maps integration, sidebar alert controls, OpenCV modal triggers, Gateway lock state).
* **`src/components/gateway/`**: Panopticon Eye 3D Vector Entry Gateway, Web Audio API synthesizer, and laser dilation transition.
* **`src/components/OpenCVFaceZoomModal.tsx`**: 8-camera CCTV surveillance matrix with Lanczos-4 biometric extraction and 6.6s verification scanner.
* **`src/components/AgentAssignmentModal.tsx`**: Live multi-agent swarm telemetry viewer (20+ OpenAI Agents SDK micro-agents).
* **`src/components/BusinessMap.tsx`**: Dark-grid radar perimeter visualization powered by Google Maps JavaScript API.
* **`src/app/api/`**: Edge API routes (`/agent-swarm`, `/opencv-matcher`, `/places`, `/trajectory-prediction`).
